# DataMind AI

## 🚀 Overview

DataMind AI is an intelligent data analysis platform that helps users analyze datasets without writing code.

Users can upload CSV files, explore data, receive AI-powered insights, generate visualizations, perform machine learning predictions, and chat with their data.

---

## 🎯 Goals

- Easy data analysis
- AI-powered insights
- Automated EDA
- Forecasting
- Machine Learning
- Report Generation

---

## 🛠 Tech Stack

Backend:
- Python

Frontend:
- Streamlit
